# Online Hospital System

CarePoint Hospital's online booking portal helps patients organise their hospital visits. The website provides an introduction to the hospital, highlights available services, and links patients to appointment booking and login pages.

## Features

- Responsive landing page for desktop, tablet, and mobile screens
- Mobile navigation menu
- Hospital information and service overview
- Links to appointment booking and login
- Contact form with required-field validation and a demo-only confirmation

## Getting started

Open `Home.html` in a browser. The site is a static front end; appointment booking and login link to their respective HTML pages. The contact form is not connected to a server and does not send or store messages.

## Project pages

- `Home.html` — landing page, services, and contact information
- `BookAppointment.html` — appointment booking form
- `Login.html` — patient login
- `MyAppointment.html` — appointment management
